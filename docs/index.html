The problem

AI coding agents waste massive amounts of tokens and time doing blind file reads. A simple 5-line fix can trigger reading 40+ files because the agent does not know where things live or how they connect.

Without ProjectBrain

Agent receives: "add discount code to checkout"

Reads 38 files. Scans routes, services, models, utilities, configs, tests. Burns through context window. Takes 90 seconds before writing a single line of code.

With ProjectBrain

Agent queries ProjectBrain first.

Gets back 3 files with line ranges, reasons, and reading order. Reads only what it needs. Starts writing code in under 5 seconds.

How it works

1

Index

Tree-sitter parses your codebase and extracts functions, classes, routes, imports, exports, and relationships into a typed graph.

2

Query

Describe your task in plain language. The query engine matches routes, symbols, imports, and traverses the graph to find connected files.

3

Navigate

Get back a focused set of files with line ranges, relevance reasons, connection chains, and a suggested reading order.

Core capabilities

Core

Graph-Aware Code Map

Goes beyond file search. Understands imports, function calls, inheritance, route-to-handler chains, and database model relationships.

Core

Explainable Results

Every result includes a reason ("defines POST /checkout", "imported by CheckoutService") and a confidence level. No black-box rankings.

Unique

Claim Verification

Verify agent assumptions against the actual code graph before they become commits. Catches hallucinations like "getUserProfile is in auth.ts" when it is not.

Unique

Stateful Sessions

Tracks what the agent has already read and edited. Follow-up queries return only the files the agent has not seen yet.

Core

Agent-Native Surfaces

Python API, CLI, and MCP server. Works with Codex, Claude Code, Cursor, Copilot, Antigravity, or any MCP-compatible agent.

Planned

Cross-Language Flow Tracing

Trace a user action from React button click through fetch call to Express route to database query. Follows the flow across language boundaries.

Core

Edge Confidence

Every relationship is labeled: exact, qualified, import-resolved, candidate, or unknown. Dynamic dispatch is flagged as approximate, not presented as fact.

Planned

Context Compression

Fits context into a token budget. Focus files get full content, connected files get signatures only, distant files get one-line summaries.

Simple API

Three lines to go from a task description to the exact files you need.

Python
from projectbrain import ProjectBrain

brain = ProjectBrain("./my-project")
brain.index()

# Natural language query — any task, not just bugs
context = brain.query("add discount code to checkout")

# Returns focused results with reasons
for result in context.results:
    print(result.file_path, result.reason)
    # src/routes/checkout.ts   "defines POST /checkout"
    # src/services/checkout.ts "handles checkout logic, imports CouponModel"
    # src/models/Coupon.ts     "coupon schema — likely needs new field"
CLI
# Index and query from the terminal
$ projectbrain index ./my-project
$ projectbrain query "why is /users returning 404"

# Structured output for piping to other tools
$ projectbrain query "add discount code to checkout" --json

# Verify an agent's claim against the code graph
$ projectbrain verify "auth.ts defines getUserProfile"
# REFUTED: getUserProfile is defined in userService.ts
MCP (for AI agents)
// Agent calls ProjectBrain via MCP before reading any files
{
  "tool": "projectbrain_query",
  "arguments": {
    "prompt": "cart total not updating after coupon applied",
    "max_results": 5
  }
}

// Response: 3 files, line ranges, reasons, reading order
// Agent reads only those files instead of scanning 40+

Architecture

Four layers, each building on the one below.

Surfaces

CLI, Python API, MCP Server

Multiple interfaces so any agent or developer can consume results in their preferred format.

Session

Session Manager, Multi-Agent Coordinator, Task Memory

Tracks what the agent has read and edited. Prevents conflicts when multiple agents work on related code.

Intelligence

Query Engine, Predictive Context, Claim Verifier, Context Compressor, Flow Tracer

Turns the raw graph into actionable answers. Routes queries, predicts file sets, verifies claims, compresses context.

Core

Tree-sitter Parser, Symbol Graph, Import Resolver, Behavioral Classifier

Extracts functions, classes, routes, imports, exports, and relationships. Builds typed edges with confidence levels.

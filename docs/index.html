Deterministic Pillars

What ProjectBrain Verifies Locally (0 LLM Tokens)

Built on bundled Tree-sitter C grammars (6 languages), Python AST dataflow, and a Salsa early-cutoff SQLite WAL code graph.

PB011

Cross-Stack HTTP Schema Solver

Verifies fetch, axios, and 1–2 hop client wrappers against FastAPI/Pydantic v1/v2, SQLModel, TypedDict, and @dataclass schemas — catching 422 missing fields, camelCase ↔ snake_case drift, response shape bugs, and HTTP verb mismatches.

PB012

React Lifecycle & Async Race Verifier

Uses Tree-sitter CST to prove inline nested component remounts, post-mount loading early-returns unmounting stateful children, and uncancelled useEffect([dep]) async setState races.

PB013

Pydantic Partial-Update & I/O Guard

Flow-sensitively catches .model_dump() / .dict() without exclude_unset=True clobbering columns in PATCH/update sinks (respecting exclude={...}) and silent except: pass around .commit() or outbound HTTP mutations.

PB002 · PB007 · PB008

Governance Tamper Lock

Enforces --forbid architectural boundaries, tracks code-native @pb-invariant: AST hashes, and blocks AI agents from deleting or weakening .projectbrain.toml / governance rules in PRs.

ROUTE · SLICE

Satellite Coordinate Router

Returns exact file:Lstart-Lend GPS coordinates, 1-hop callers/callees, HTTP route peers, covering tests, and invariants in ~500 tokens — letting agents use native read_file/edit_file without truncated dumps.

SARIF · CI

Sub-2s PR Merge-Base Gate

Diffs multi-commit PRs cleanly against git merge-base and outputs text, JSON, GitHub annotations, sticky Mermaid PR impact summaries, or OASIS SARIF v2.1.0 with zero cloud code egress.

Stack Fit & Honest Tradeoffs

Pairs With Your Compilers — Never Replaces Them

Layer What It Catches Blind Spot ProjectBrain's Slot (--profile fullstack)
ruff / pyright / tsc / eslint Single-language syntax, static types, lints Blind across Python ↔ TS HTTP boundaries & repo invariants Cross-stack schema solver (PB011), React races (PB012), Pydantic clobbers (PB013)
Cloud AI PR Reviewers High-level logic & prose review 30–90s latency, probabilistic noise, cloud code egress <2s deterministic local/CI SARIF gate, zero API keys, Apache-2.0
Coding Agents & Swarms Fast rg, parallel edits, multi-file refactors Break uninspected callers, drift past invariants, tamper with configs Post-edit hooks, tamper-locked rules (PB007), shared ~500-token coordinate routing

Where ProjectBrain Shines

  • Monorepos pairing FastAPI / Pydantic / SQLModel backends with hand-written React / TypeScript fetch or axios clients.
  • Teams reviewing high-volume AI-generated PRs who want deterministic, zero-token CI gates for layer rules and business invariants.
  • Sub-second incremental local checks (~515ms body edits on 3,051-file Django repos via SQLite WAL + Salsa early-cutoff).

Honest Boundaries Today

  • Monorepo required for PB011: Split frontend/backend repos and generated OpenAPI SDKs (where tsc already checks generated types) don't need PB011.
  • Express routes: Currently verifies HTTP verbs and path matching, not Zod/Joi request/response body schemas.
  • Dynamic runtime dispatch: Static analysis cannot prove calls through runtime-resolved adapters; verify honestly returns UNKNOWN.

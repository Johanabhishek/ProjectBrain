Setup in 60 Seconds

Let agents edit natively with Edit / edit_file while ProjectBrain handles deep graph discovery and real-time regression interception automatically.

Step 1 Install via uv (or pipx)

Install isolated projectbrain and projectbrain-mcp binaries with zero PEP 668 system-Python friction:

uv tool install projectbrain-mcp
# Or: pipx install projectbrain-mcp
# Or inside a virtualenv: pip install projectbrain-mcp

Step 2 Initialize Your Repository

Index the codebase into .projectbrain.db, wire ENOENT-proof MCP configs, and enable active post-edit hooks:

projectbrain --path /path/to/your/repo init --git-hook

What init configures non-destructively:
1. Builds .projectbrain.db (SQLite WAL + FTS5) honoring .gitignore.
2. Resolves absolute executable paths so GUI IDEs never fail with spawn ENOENT.
3. Installs active Claude Code PostToolUse (.claude/settings.local.json), Cursor afterFileEdit (.cursor/hooks.json), and optional Git pre-commit guardrails.
4. Leaves .projectbrain_memory.json git-trackable so pinned invariants and --forbid boundary rules travel with your team's PRs.

Step 3 Add the <2s GitHub Actions PR Gate

Enforce cross-file contracts, architectural boundaries, and invariant checks on every pull request:

name: ProjectBrain Architecture & Contract Gate
on: [pull_request]
jobs:
  guardrail:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
        with:
          fetch-depth: 0
      - uses: astral-sh/setup-uv@v4
      - run: uvx --from projectbrain-mcp projectbrain check --ci

Offense + Defense Workflow

Use ProjectBrain from your terminal, CI pipeline, or automatically through its 5-tool MCP server and active editor hooks.

1. Compile a 1-Turn Architecture Dossier (dossier)
# Prints class-qualified AST slices, 1-2 hop call/state chains, and covering tests directly to stdout
$ projectbrain --path /path/to/repo dossier "how are exceptions routed to error handlers"
2. Surgical Symbol & Intra-Function PDG Slicing (slice --focus)
# Slice exact backward defs + forward uses + control guards for a variable in <20ms from SQLite
$ projectbrain --path /path/to/repo slice billing.py:compute_invoice --focus discount_total
3. Pin Enforceable Layer Boundaries & AST Invariants (remember)
# Block forbidden cross-layer imports/calls in real-time hooks and CI
$ projectbrain --path /path/to/repo remember --forbid "routes/* -> db/*" --reason "Routes must call services/*"
$ projectbrain --path /path/to/repo remember settle_invoice "Must preserve idempotency on duplicate invoice_id"
$ projectbrain --path /path/to/repo memories
4. Guardrail Scorecard & PR Reports (check & stats --summary)
$ projectbrain --path /path/to/repo check --format markdown
$ projectbrain --path /path/to/repo stats --summary

Core Capabilities

Defense

Active Post-Edit Firewall (hooks.py)

Audits native Edit / Write changes in real time. Emits zero bytes when clean; catches syntax errors, broken caller arity, layer violations, signature blast radius, and mutated invariants.

Offense

1-Turn Engineering Dossier (brain_dossier)

Compiles class-qualified AST slices, 1–2 hop caller/callee skeletons, HTTP/state flows, and covering tests in one call.

Slicing

<20ms SQLite + PDG Slicer (brain_slice)

Extracts exact symbol bodies or variable-focused intra-function Program Dependence Graph slices (--focus var) without loading full files.

Epistemic

3-Valued Claim & CI Gate (brain_check)

Verifies structural claims (SUPPORTED / REFUTED / UNKNOWN) and 4-pillar contracts, outputting Ruff-style text, PR markdown, or GitHub Actions annotations.

Governance

Enforceable Repo Memory (brain_remember)

Git-tracked .projectbrain_memory.json stores AST-hash symbol invariants and enforceable --forbid "src/* -> dst/*" boundary rules.

Graph

Polyglot Route & Import Resolution (brain_explore)

Resolves Python relative/barrel imports, TypeScript tsconfig aliases, CommonJS prototypes, and FastAPI, Flask, Django, Next.js, Express, and Hono routes.

Setup in 60 Seconds

Let agents edit natively with Edit / edit_file while ProjectBrain handles deep graph discovery and real-time regression interception automatically.

Step 1 Install via uv (or pipx)

Install isolated projectbrain and projectbrain-mcp binaries with zero PEP 668 system-Python friction:

uv tool install projectbrain-mcp
# Or: pipx install projectbrain-mcp
# Or inside a virtualenv: pip install projectbrain-mcp

Step 2 Initialize Your Repository (Personal or Team + CI Mode)

Index the codebase into .projectbrain.db, wire MCP + editor hooks, and optionally bootstrap OS-portable team configs, GitHub Actions, and Day-1 governance:

# Personal workstation (ENOENT-proof absolute IDE paths):
projectbrain --path /path/to/your/repo init --git-hook

# Team + CI setup (OS-portable hooks, GitHub Action workflow, & zero-violation rule discovery):
projectbrain --path /path/to/your/repo init --team --learn

What init --team --learn configures non-destructively:
1. Builds .projectbrain.db (SQLite WAL + FTS5) honoring .gitignore.
2. Writes OS-portable .claude/settings.json, .cursor/hooks.json, .mcp.json, and .github/workflows/projectbrain.yml with zero local machine paths.
3. Runs projectbrain learn to auto-discover zero-violation --forbid layer boundaries and git co-change contracts on Day 1.
4. Leaves .projectbrain_memory.json git-trackable and protected by the Governance Tamper Lock across every PR.

Step 3 Automated PR Merge-Base Gate, SARIF v2.1.0 & Sticky Mermaid Comments

Generated automatically by projectbrain init --team in .github/workflows/projectbrain.yml — audits multi-commit PRs against git merge-base, uploads OASIS SARIF v2.1.0 to GitHub Code Scanning, and upserts a zero-noise sticky PR comment (<!-- projectbrain-pr-guardrail -->) with Mermaid blast-radius graphs:

# CLI equivalents run in CI (auto-detects GITHUB_BASE_REF / GitLab MR / Bitbucket / Azure PR envs):
projectbrain check --base main --format sarif > projectbrain.sarif
projectbrain check --base main --format pr-comment > projectbrain-pr-comment.md
projectbrain check --base main --ci

Offense + Defense Workflow

Use ProjectBrain from your terminal, CI pipeline, or automatically through its 5-tool MCP server and active editor hooks.

1. Zero-Config Day-1 Architecture & Co-Change Discovery (learn)
# Auto-discover zero-violation --forbid layer rules, git co-change contracts, and high-fan-in hub symbols
$ projectbrain --path /path/to/repo learn
$ projectbrain --path /path/to/repo learn --apply
2. Compile a 1-Turn Architecture Dossier & <20ms PDG Slice (dossier / slice --focus)
# Prints class-qualified AST slices, 1-2 hop call/state chains, and covering tests directly to stdout
$ projectbrain --path /path/to/repo dossier "how are exceptions routed to error handlers"
$ projectbrain --path /path/to/repo slice billing.py:compute_invoice --focus discount_total
3. Pin Enforceable Boundaries, Co-Change Contracts & AST Invariants (remember)
# Protected against silent agent tampering in PRs by the Governance Tamper Lock
$ projectbrain --path /path/to/repo remember --forbid "routes/* -> db/*" --reason "Routes must call services/*"
$ projectbrain --path /path/to/repo remember --co-change "schema.sql <-> models/user.py" --reason "Keep ORM synced"
$ projectbrain --path /path/to/repo remember settle_invoice "Must preserve idempotency on duplicate invoice_id"
4. Whole-Repo Semantic Triage (check --audit), PR Merge-Base Gate, OASIS SARIF v2.1.0 & Scorecard
$ projectbrain --path /path/to/repo check --audit
$ projectbrain --path /path/to/repo check --base main --ci
$ projectbrain --path /path/to/repo check --base main --format pr-comment
$ projectbrain --path /path/to/repo check --base main --format sarif > projectbrain.sarif
$ projectbrain --path /path/to/repo stats --summary

Core Capabilities

Defense

Active Post-Edit Firewall (hooks.py)

Audits native Edit / Write changes in real time. Emits zero bytes when clean; catches syntax errors, broken caller arity, layer violations, signature blast radius, and mutated invariants.

Offense

1-Turn Engineering Dossier (brain_dossier)

Compiles class-qualified AST slices, 1–2 hop caller/callee skeletons, HTTP/state flows, and covering tests in one call.

Slicing

<20ms SQLite + PDG Slicer (brain_slice)

Extracts exact symbol bodies or variable-focused intra-function Program Dependence Graph slices (--focus var) without loading full files.

CI / PR Gate

Whole-Repo Semantic Triage, PR Merge-Base & SARIF v2.1.0 (brain_check)

Runs <1.5s whole-repo anomaly triage via check --audit, audits committed PR branches via check --base main, verifies 3-valued claims (SUPPORTED / REFUTED / UNKNOWN), emits OASIS SARIF v2.1.0 (PB001–PB013, incl. PB011 HTTP schemas, PB012 React remounts, PB013 Pydantic clobbers), and renders sticky PR comments with Mermaid blast-radius graphs.

Governance

Tamper-Locked Governance & Day-1 learn

Auto-discovers zero-violation --forbid boundaries and git co-change contracts via projectbrain learn, and blocks unauthorized rule deletion or hash tampering in PRs via the Governance Tamper Lock.

Graph

Polyglot Route & Import Resolution (brain_explore)

Resolves Python relative/barrel imports, TypeScript tsconfig aliases, CommonJS prototypes, and FastAPI, Flask, Django, Next.js, Express, and Hono routes.
